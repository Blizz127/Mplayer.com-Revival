What is this?

Mplayer.com (Mpath Interactive, 1996–2001) was a pioneering free online service for playing PC games together, with chat rooms, animated emotes, and real-time voice. It was absorbed into GameSpy and shut down in 2001. This project brings it back the same way the GameSpy and TEN revivals did: preserve the original client, reverse-engineer its protocol, and re-stand-up the servers it used to talk to.

How it comes back

  1. Preserve the original client. done
  2. Reverse-engineer the wire protocol (login, lobby, matchmaking, voice).
  3. Reimplement the servers in Python.
  4. Redirect the client's old hostnames to them — no binary patching.

Two clients, one protocol: the original client (faithful) and a new cross-platform client that runs natively on Windows 11, macOS & Linux.
